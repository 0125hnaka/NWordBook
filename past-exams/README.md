# ネットワークスペシャリスト 午後試験PDF

出典：IPA 独立行政法人情報処理推進機構。

2009〜2019年度秋期、2021〜2025年度春期のネットワークスペシャリスト試験、午後Ⅰ／午後Ⅱ。問題冊子・解答例・採点講評の計96ファイルです。原本PDFは改変していません。各年度・期・時間区分・資料種別・出典URL・SHA-256はmanifest.jsonに記録しています。問番号・設問番号は各PDF内を参照してください。

- [IPA公式の過去問題一覧](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)
- [IPAの過去問題使用条件](https://www.ipa.go.jp/shiken/faq.html)
- [アプリで解く](https://0125hnaka.github.io/NWordBook/exam.html)
- [PDFフォルダーを含む一式をZIPでダウンロード](https://github.com/0125hnaka/NWordBook/archive/refs/heads/main.zip)

アプリでは年度・時間区分を選ぶとこのフォルダーから自動表示します。初回取得後はブラウザー内の保存を優先します。iPhone・iPadでは「PDFの保存・使い方」内の「すべてのPDFをこの端末に保存」でまとめて保存できます。Safariがファイルアプリ内のフォルダーを自動参照する方式ではありません。回答は各端末のブラウザー内に保存され、この公開フォルダーには含まれません。
