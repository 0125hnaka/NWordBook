# 質問用の問題識別番号

各問題の問題文の直前に小さく表示する固定番号。セッション内の「QUESTION 01」とは別で、出題順・分野・学び方・復習・端末によって変わらない。

- 通常問題：Q001～Q952（原本852問と用語カード100枚）。
- 予想問題：P01～P78（短問72問と複合演習6問）。
- 同じ用語の「説明→名前」「名前→説明」は別問題なので、それぞれ別の番号。
- 非表示一覧にも番号を表示する。以前からの理解度・非表示記録は従来の内部IDで保持する。

ユーザーは、このチャットで「Q123の問題は？」「P05の解説をもっと詳しく」のように質問できる。AIがアプリに自動接続する機能ではなく、保存した対応表と教材を照合して回答するための番号。

## 問題を調べる

リポジトリのルートで実行する。

```sh
node scripts/find-question.mjs Q123
node scripts/find-question.mjs P05
```

小文字・全角英数字・ゼロ省略にも対応する（q1／Ｑ１はQ001、p5はP05）。問題文・解答・解説・注意点・出典を出力する。ユーザーの質問番号を、セッション内の何問目という意味に読み替えない。

## 更新ルール

対応表はdata/editorial/question_codes.json。初回に全1,030問題を採番済み。通常のビルドや再読み込みでは採番し直さず、必ずこの対応表から割り当てる。

新しい問題は未使用の番号を追加する。既存の番号と内部IDの組合せを変更しない。削除した問題の番号も予約として残し、他の問題へ再利用しない。教材内で問題の配列順を変えても番号は変わらない。質問への回答時は、コードを記憶で推測せず検索して確認する。
