# 予想問題

2026年10月17日のユーザー提供資料「追加調査_2026-10-17」を追加演習として収録した。通常の過去問由来の学習を主とし、ホームの開始ボタンの下にある「予想問題を解く」からだけ専用画面へ入る。短問72問と複合演習6問の計78問。

## 出題実績との区別

提供資料では全項目のIPA出題対応が未調査とされている。「過去に一度も出題されていない」「今後必ず出題される」とは扱わない。根拠リンクは技術説明の根拠で、IPA出題実績や出題確率を示さない。A/Bは資料独自の学習順。複合演習には資料にない優先度を追加しない。

通常教材952枚、研究原本852問、確認済み836問、知識原子366件、頻度・優先100・通常の学習分野設定を変更していない。予想問題はcatalog.predictionCardsへ分け、通常のcatalog.cardsには追加しない。

## 操作

- 専用画面では短問／複合演習／両方と、5・10・20問・すべてを選べる。
- 通常の学び方・学習分野・未確認補充スイッチとは独立して出題する。予想問題の問題数はpredictionQuestionCountとして別保存。
- 理解度記録、苦手問題だけの復習、前の問題・番号指定での見直し、元の問題への復帰に対応。
- 予想問題も非表示一覧で「予想問題」と表示し、復活できる。理解度と非表示はPRED_で始まる別IDで保存・バックアップする。
- カードには予想問題であることを表示し、解答後の「予想問題の根拠・関連資料」で出典・注意条件・既存との差分を確認できる。複合演習では関連短問の技術資料を示す。

## 原稿と変換

再変換：`node scripts/import-predictions.mjs`
