# 単語帳の詳しい解説

2026年10月19日追加。通常952問（原本852問と追加用語100枚）、予想78問の全1,030問で利用できます。午後試験の大問用解説とは別の教材です。

「答えを見る」を押すと、元の短い解説の下に次の三段を表示します。詳しい解説自体は折り畳まず、用語問題でも読めます。

1. **前提となる知識**：関連する仕組みと用語の役割。
2. **具体例で考える**：IP、経路情報、設定、時刻、計算値などを使った例と、その条件での結果。
3. **答えにつながる理由**：元の知識の仕組みや、予想問題の理由・解答の骨子。

同じ知識に対応するカードは、前提知識と具体例を共有します。通常の366知識と予想78問のそれぞれに具体例を用意し、共通文を一律に付けるだけの補完はしません。例の数値・構成は理解のための仮定であり、設問の条件が優先です。追加例がIPA原問の記述そのものであるとは扱いません。

Q055にはCNAMEと参照先Aの管理者・キャッシュ、Q141には経路情報の再配送・AS_PATHの消失・タグと経路選択条件、Q218には実際のTCP接続先とPAC、Q245にはキュー廃棄・受信確認・ポーリング間隔を補足しています。

## データと編集

- 原本 `data/source/`、短い解答と解説、固定問題番号、学習状態の保存IDは維持します。
- 追加教材は `data/editorial/detailed_explanations.json` に格納します。
- 著作元は `scripts/details/lessons.mjs`（前提知識）、`atoms-1.mjs`〜`atoms-4.mjs`（知識別の具体例）、`predictions.mjs`（予想問題別の具体例）です。
- 各行は `IDの接尾辞|前提知識のID|具体例`。段落の区切りは文字列内の `\n` で指定します。
- `node scripts/author-detailed-explanations.mjs` でJSONを再作成します。再生成時に重複、参照、全件の対応を検証します。
- `node scripts/validate.mjs`、`node --test`、`node scripts/build.mjs`（または `npm run check`）で公開前に検証します。

画面表示時は従来のIPA用語変換を適用し、本文をHTMLとして解釈しません。解説追加によって出題数、出典の確認状態、頻度、非表示・理解度の記録を変更しません。PCとスマートフォン幅で本文を折り返します。
