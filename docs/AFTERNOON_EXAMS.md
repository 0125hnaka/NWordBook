# 午後試験を解く

ホームの「午後試験を解く」から開く、ネットワークスペシャリスト専用の大問練習ページです。

## 使い方

1. 年度、午後Ⅰ／Ⅱ、大問を選びます。
2. 対応するPDFが自動で開きます。保存済みなら端末内から、初回ならアプリ内のPDFフォルダーから取得します。
3. ページ番号・前後ボタンで問題へ移動します。「ページ全体」は表示領域に収め、「幅に合わせる」はページを大きくします。どちらもビューワ内にスクロール枠はありません。資料は問題／公式解答例／採点講評を切り替えられます。
4. 右側（スマホは下側）の設問番号・空欄記号・欄見出しに沿って回答します。
5. 「回答まとめへ」で末尾へ移動し、「回答をコピー」を押します。現在の大問の全回答に設問番号が付き、未記入は「未回答」と表示されます。

公式PDF96件は、2026-10-18のユーザー指示でリポジトリの `past-exams/` と既存Pagesへ公開しました。原本のSHA-256を確認してから同梱PDF.jsで描画します。表示の都度IPAへ接続しません。問題PDFは冊子全体なので、大問の先頭へはページ番号で移動してください。大問を切り替えた際は公式解答例を閉じて問題表示に戻ります。

## 保存・持ち運び

- PDF保存先：公開リポジトリの `past-exams/`。`manifest.json` に取得元・年度・区分・ハッシュ・サイズを記録。以前のPC内 `../past-exams-local/` はそのまま残しています。
- アプリは `nwordbook:exam-pdfs:v1` というCacheStorageへ検証済みのPDFを保存します。再読込み後も保存を優先し、同じPDFの表示とまとめ保存が重なった場合は取得を共有します。破損した保存は再取得し、容量不足などでは保存失敗を表示してPDF表示は続けます。
- 回答は `nwordbook:exam-answers:v1` という別のブラウザー保存キーへ入力ごとに保存。大問・年度の切り替えや再読込み後も復元します。単語帳の理解度・設定には影響しません。
- 「全年度の回答をバックアップ」で回答をJSON保存。読み込み時は件数を確認してから適用し、同じ欄の回答だけを上書きします。
- ブラウザーの保存が使えない／容量不足の場合は一時保存を明示し、入力内容を保持したままバックアップできます。破損した元の保存内容を自動で上書きしません。
- iPhone・iPadでは同じ公開ページを開くだけで自動取得できます。「PDFの保存・使い方」内の「すべてのPDFをこの端末に保存」で全96件、約122MBを保存できます。途中中断・失敗でも保存済みのものは保持します。
- ファイルとして持ち運ぶ場合は「PDFを含む一式をダウンロード」でGitHubのZIPを保存します。Safariはファイルアプリ内のフォルダーを自動参照できないため、アプリの自動表示にはブラウザー内の保存を使います。ブラウザーデータの削除や端末の空き容量によって保存が消えることがあります。PDF保存機能は、アプリ全体の完全なオフライン起動を保証するものではありません。

## 対象と回答欄

2026-10-18時点の[IPA過去問題一覧](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)に掲載されている現行NW区分の16回分（2009〜2019年秋期、2021〜2025年春期）。32問題冊子・80大問です。解答例32・採点講評32も取得し、計96PDFのハッシュ一致を確認しています。2020年度のNWはありません。2008年以前の旧区分（テクニカルエンジニア等）は対象外です。

既存調査の全1,345回答単位を採用し、短問化時に除外した局所的な値や図表問題も含めています。公式解答表の欄見出しを使って175回答単位を細分化し、計1,559入力欄を用意しました。空欄記号、複数の機器、理由／処理、ヘッダー表などに個別の欄を設けています。複合・結合セルを補正した欄構成は `data/exams/answer-parts.json` に記録しています。公式の解答本文はアプリのJSONへ含めていません。

図や経路の描画ツールはありません。機器名・接続先・行見出しを付けて文字で記入します。字数カウンターは目安で、字数制限・単位・選択数は問題PDFの指示に従います。自動採点・試験時間計測・本番形式の複数大問受験には対応していません。2024午後Ⅱ問2設問5の3設問は公式の不備公表を明示しています。

## 開発・再取得

`node scripts/download-exams.mjs` で96PDFを `past-exams/` へ保存／検証します。一致済みのPDFは再取得しません。不一致やHTTPエラーなら停止し、未検証の内容で上書きしません。表示ページからこの処理を呼ぶことはありません。ビルド時も96件すべての原本ハッシュを検証し、公開対象として定義したPDFだけを配信先へコピーします。個人の回答ファイルは含めません。

`node scripts/import-exams.mjs` は隣の読取り専用調査資料から設問番号・出典を取り込み、上記の欄構成を付加します。元資料を変更しません。既存の設問IDや細分化した欄の順序を変更すると保存回答の対応が変わるため、テストで固定しています。

## 出典・ライセンス

- 出典は各大問の画面末尾へ年度・期・試験区分・時間区分・問番号を表示。原本PDFは改変しません。独自作成の回答欄であることを併記します。[IPAの使用条件](https://www.ipa.go.jp/shiken/faq.html)を確認しています。
- PDF.js（Mozilla / `pdfjs-dist` 6.4.299）をApache-2.0で同梱。配布元・配布ハッシュは `vendor/pdfjs-6.4.299/SOURCE.json`、ライセンスは同フォルダーのLICENSEと各フォント・デコーダーのライセンスを参照。外部CDNには接続しません。
