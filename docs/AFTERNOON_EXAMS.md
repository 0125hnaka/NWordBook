# 午後試験を解く

ホームの「午後試験を解く」から開く、ネットワークスペシャリスト専用の大問練習ページです。

## 使い方

1. 年度（令和・平成の和暦表記）、午後Ⅰ／Ⅱ、大問を選びます。
2. 対応するPDFが自動で開きます。保存済みなら端末内から、初回ならアプリ内のPDFフォルダーから取得します。
3. ページ番号・前後ボタンで問題へ移動します。「ページ全体」は表示領域に収め、「幅に合わせる」はページを大きくします。どちらもビューワ内にスクロール枠はありません。資料は問題／公式解答例／採点講評を切り替えられます。
4. 右側（スマホは下側）の設問番号・空欄記号・欄見出しに沿って回答します。「設問1」「設問2」などの見出しを押すと、その設問の解答欄・自己採点欄をまとめて開閉できます。入力や採点は保持し、閉じた見出しにも記入済みの欄数を表示します。同じページを開いている間は、大問を行き来しても開閉状態を保持します。再読込み時は開いた状態へ戻ります。
5. 「回答まとめへ」で末尾へ移動し、「回答をコピー」を押します。現在の大問の全回答に設問番号が付き、未記入は「未回答」と表示されます。

公式PDF96件は、2026-10-18のユーザー指示でリポジトリの `past-exams/` と既存Pagesへ公開しました。原本のSHA-256を確認してから同梱PDF.jsで描画します。表示の都度IPAへ接続しません。問題PDFは冊子全体なので、大問の先頭へはページ番号で移動してください。大問を切り替えた際は公式解答例を閉じて問題表示に戻ります。

## 保存・持ち運び

- PDF保存先：公開リポジトリの `past-exams/`。`manifest.json` に取得元・年度・区分・ハッシュ・サイズを記録。以前のPC内 `../past-exams-local/` はそのまま残しています。
- アプリは `nwordbook:exam-pdfs:v1` というCacheStorageへ検証済みのPDFを保存します。再読込み後も保存を優先し、同じPDFの表示とまとめ保存が重なった場合は取得を共有します。破損した保存は再取得し、容量不足などでは保存失敗を表示してPDF表示は続けます。
- 回答は `nwordbook:exam-answers:v1` という別のブラウザー保存キーへ入力ごとに保存。大問・年度の切り替えや再読込み後も復元します。単語帳の理解度・設定には影響しません。
- 「全年度の回答をバックアップ」で回答・採点・時間をJSON保存。読み込み時は件数を確認してから適用し、同じ欄の回答だけを上書きします。
- ブラウザーの保存が使えない／容量不足の場合は一時保存を明示し、入力内容を保持したままバックアップできます。破損した元の保存内容を自動で上書きしません。
- iPhone・iPadでは同じ公開ページを開くだけで自動取得できます。「PDFの保存・使い方」内の「すべてのPDFをこの端末に保存」で全96件、約122MBを保存できます。途中中断・失敗でも保存済みのものは保持します。
- ファイルとして持ち運ぶ場合は「PDFを含む一式をダウンロード」でGitHubのZIPを保存します。Safariはファイルアプリ内のフォルダーを自動参照できないため、アプリの自動表示にはブラウザー内の保存を使います。ブラウザーデータの削除や端末の空き容量によって保存が消えることがあります。PDF保存機能は、アプリ全体の完全なオフライン起動を保証するものではありません。

## 対象と回答欄

2026-10-18時点の[IPA過去問題一覧](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)に掲載されている現行NW区分の16回分（2009〜2019年秋期、2021〜2025年春期）。32問題冊子・80大問です。解答例32・採点講評32も取得し、計96PDFのハッシュ一致を確認しています。2020年度のNWはありません。2008年以前の旧区分（テクニカルエンジニア等）は対象外です。

既存調査の全1,345回答単位を採用し、短問化時に除外した局所的な値や図表問題も含めています。公式解答表の欄見出しを使って175回答単位を細分化し、計1,559入力欄を用意しました。空欄記号、複数の機器、理由／処理、ヘッダー表などに個別の欄を設けています。複合・結合セルを補正した欄構成は `data/exams/answer-parts.json` に記録しています。全16回の解答例と独自解説を年度別JSONに収録しています。

図や経路の描画ツールはありません。機器名・接続先・行見出しを付けて文字で記入します。字数カウンターは目安で、字数制限・単位・選択数は問題PDFの指示に従います。自動採点・本番形式の複数大問受験には対応していません。大問別の自己採点・時間計測に対応しています。2024午後Ⅱ問2設問5の3設問は公式の不備公表を明示しています。

## 自己採点・解説・タイマー（v0.6.0）

「自己採点を始める」を押すとタイマーが中断し、公式解答例PDFと各項目の○△×が表示されます。○は100%、△は50%、×は0%として、大問内の回答項目を均等配点し100点換算します。複数入力欄のある項目は全欄をまとめて1項目として判断します。未採点は暫定0点で件数を併記します。公式配点ではなく学習の目安です。2024午後Ⅱ問2設問5の不備3項目は採点の分母から除外します。

記述問題は、主語・対象・動作・理由などの必要な要点を比較して自己採点します。言い換えや部分点を人が柔軟に判断する方式です。用語も含め自動の正誤判定は行いません。採点時の回答を記録し、回答の変更後は古い採点を得点に含めず再採点を促します。AI/APIの設定や追加料金は発生しません。

全16回の午後Ⅰ48大問・午後Ⅱ32大問、計1,345項目は「解説を読む」から専用ページへ移れます。解答例、解く道筋、必要知識、本文の参照ページ・注目点、定石、自己採点の観点を設問ごとに記載しました。知／思／定／本は、それぞれ知識／思考／定石／本文を示し、特に使う力にマークを付けています。解説ページの採点も回答画面と共通です。全年度で公式解答例・採点講評PDFと併せて確認できます。不備公表の2024年度午後Ⅱ問2・設問5(1)〜(3)にも採点対象外である旨を記載しています。

大問を選び「開始」で計測、「中断」「再開」で時間を保持します。「時間をリセット」は現在の大問の時計のみを0へ戻します。大問・年度の切替、解説への移動、ページを離れる操作で時計は中断し、再開は手動です。ブラウザーを開いたまま別アプリを見る時間は計測に含みます。端末の時計を基準にするため端末時刻の変更の影響を受けます。本番の複数大問をまとめた試験時間ではありません。

採点・時間は `nwordbook:exam-practice:v1` に保存します。回答バックアップに任意の `practice` セクションを追加し、旧形式の回答のみのバックアップも読み込めます。バックアップ内の時計は保存時点で中断した状態にします。復元時は対象IDだけを更新し、他の大問は保持します。取り込み上限は全体20MB、回答部分5MB、採点・時間部分10MBです。保存不能時は解説ページからも一時保存中の採点をバックアップできます。

解説の編集元は `scripts/explanations/<year>.mjs`、生成先は `data/exams/explanations/<year>.json` です。`node scripts/author-explanations.mjs` で再生成します。先行公開した2025年度は `scripts/author-explanations-2025.mjs` と `data/exams/explanations-2025.json` を保持し、`scripts/explanation-data.mjs` が全年度を統合します。本文の図・表・条件を公式問題冊子で確認し、解答例と照合して編集します。ビルドは全80大問の完全収録と、全設問ID・必要項目・出典ファイル・参照ページを検証します。不足・重複があると公開用ビルドを停止します。独自の短問教材に一般化された説明を、原問の解説へそのまま転用しません。

## 開発・再取得

`node scripts/download-exams.mjs` で96PDFを `past-exams/` へ保存／検証します。一致済みのPDFは再取得しません。不一致やHTTPエラーなら停止し、未検証の内容で上書きしません。表示ページからこの処理を呼ぶことはありません。ビルド時も96件すべての原本ハッシュを検証し、公開対象として定義したPDFだけを配信先へコピーします。個人の回答ファイルは含めません。

`node scripts/import-exams.mjs` は隣の読取り専用調査資料から設問番号・出典を取り込み、上記の欄構成を付加します。元資料を変更しません。既存の設問IDや細分化した欄の順序を変更すると保存回答の対応が変わるため、テストで固定しています。

## 出典・ライセンス

- 出典は各大問の画面末尾へ年度・期・試験区分・時間区分・問番号を表示。原本PDFは改変しません。独自作成の回答欄であることを併記します。[IPAの使用条件](https://www.ipa.go.jp/shiken/faq.html)を確認しています。
- PDF.js（Mozilla / `pdfjs-dist` 6.4.299）をApache-2.0で同梱。配布元・配布ハッシュは `vendor/pdfjs-6.4.299/SOURCE.json`、ライセンスは同フォルダーのLICENSEと各フォント・デコーダーのライセンスを参照。外部CDNには接続しません。
